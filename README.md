# astrbot_plugin_douyin_live

抖音直播开播检测插件（AstrBot v4）

- 订阅主播直播间，每 5 分钟轮询一次开播状态
- 支持直接粘贴手机 App 分享出来的整段文本（自动解析 v.douyin.com 短链）
- 开播/下播自动推送「封面图 + 直播间链接 + 配文」到指定群
- 群聊里说触发词（如「看看腿」）即时检查并回复正在直播的主播

## 检测原理

- 19 位房间 id（手机分享链接解析出来的）→ 直接 HTTP 拉 reflow 分享页判断，无需浏览器，秒出结果
- 12 位左右的直播间号（live.douyin.com 地址里的）→ Playwright 无头浏览器渲染页面判断
  - 开播：页面含「在线观众 / 本场点赞」或标题含「xxx的抖音直播间」
  - 未开播：页面含「未开播 / 暂未开播 / 直播回放」

抖音 web 接口（webcast enter）带签名校验，直接 HTTP 调用会被拒，因此直播间号走页面渲染最稳。
默认使用系统 Edge（`msedge`），无需额外下载浏览器；也可留空用 Playwright Chromium（需先 `playwright install chromium`）。

## 直播间号怎么看

直播间号 = `live.douyin.com/` 后面那串数字。获取方式（参考抖音官方页面及公开教程）：

1. **最省事（推荐）**：手机抖音 App 进入主播直播间 → 右上角「…」→ 分享 → 复制链接，
   会得到一段分享文本（形如 `#在抖音，记录美好生活#【xxx】正在直播… https://v.douyin.com/xxxx/ …`）。
   **把整段文本直接粘给机器人订阅即可**，插件会自动展开短链拿到 19 位房间号，不用自己找。
2. **电脑端**：浏览器打开主播正在播的直播间，地址栏 `https://live.douyin.com/123456789012/`
   里的数字就是直播间号。
3. **分享短链**：`https://v.douyin.com/xxxx/` 直接丢给机器人也行，会自动解析。

> 通过抖音号锁定直播间（自测可用）：用无头浏览器访问 `https://www.douyin.com/user/{抖音号}`，
> 页面 HTML 里的 `web_rid=xxxx` 就是你的直播间号，可直接用于订阅。

### 订阅自己的直播间（主播本人，推荐）——用直播伴侣的 user_id

如果你是主播本人、要用「抖音直播伴侣」开播，那么**你的直播间号需要从直播伴侣里复制**：

1. 打开「抖音直播伴侣」
2. 右上角 →「关于」（或「帮助 → 关于」）
3. 里面能看到 `用户：一串数字`（例如 `用户：7655359974512804921`），这就是你的 user_id

把这个 user_id（或者你直播间的 web_rid / 直播分享短链）填进订阅即可。
订阅时填抖音号 `Lianmin726` 也能通过无头浏览器自动解析出直播间号。

> 说明：抖音 web 的搜索/用户接口需要登录态签名，部分接口（webcast enter）直接 HTTP 调用会被拒，
> 插件用无头浏览器渲染 + 页面昵称校验来精准判定，避免把路由到别人的页面误判成开播。

## 用法

| 命令 | 说明 |
| --- | --- |
| `订阅 <直播间号/直播间链接/手机分享整段文本>` | 订阅，成功后回复「订阅直播成功」 |
| `取消订阅 <直播间号>` | 取消订阅 |
| `订阅列表` | 查看全部订阅及当前开播状态 |
| `直播转发 <群号>` | 开播推送转发到指定群 |
| `取消转发 <群号>` | 移除转发群 |
| `转发列表` | 查看转发群 |
| `添加触发词 <词>` | 逐个添加触发词（不要用逗号隔开，一个个加） |
| `删除触发词 <词>` | 删除某个触发词 |
| `触发词列表` | 查看当前全部触发词 |
| 触发词（默认：看看腿 等） | 即时检查，有在播的发封面+链接+配文，全没播回「都还没开播呢」 |

## 依赖

- Python 依赖见 `requirements.txt`（playwright、aiohttp）
- 系统浏览器：Edge（默认）或 Playwright Chromium

## 配置项

- `enabled`：启用开关
- `trigger_words`：触发词列表（在面板里逐个添加，或在群里用「添加触发词」命令）
- `sub_room_ids`：订阅直播间号 list，逐项填写房间号 / live.douyin.com 链接 / v.douyin.com 短链均可，保存/启动时会自动解析成房间号
- `forward_groups`：转发群号 list，逐项填 QQ 群号，开播时推送到这些群
- `reply_text`：开播配文
- `not_live_text`：全部未开播时的回复，留空不回复
- `poll_interval`：轮询间隔秒数（默认 300）
- `fetch_cover`：是否发送封面图
- `ttwid`：可选，浏览器登录抖音后从 Cookie 复制的 ttwid，填了更不容易被风控
- `browser_channel`：`msedge`（默认）或留空用 Playwright Chromium
